# AMYboard Online を使う

[amyboard.com](https://amyboard.com/editor) にある AMYboard のウェブエディタでは、ブラウザ内で AMYboard をシミュレートしたり（AMYboard が手元になくてもスケッチを設計できます）、手持ちの AMYboard を MIDI 経由で直接制御したりできます。AMYboard World で共有されているスケッチを見ることもできます。


最初に読み込むと次の画面が表示されます。AMYboard をシミュレートするか、自分のものを制御するかを選べます。

<img src="../../docs/amyboard/img/simulate_control.png">

## Control モード

**Control モードで AMYboard Online を使う前に、[ファームウェアをアップグレード](firmware.md)しておいてください。**

Control モードを使いたい場合は、まず AMYboard が MIDI でコンピュータに接続されていることを確認します。

USB-C ポートだけでも使えます。MIDI の入出力ポートが公開されます。USB-C MIDI を使っている場合は自動で検出します。

USB-C ポートにアクセスできない場合や、直接 MIDI を使いたい場合は、AMYboard の MIDI 出力・入力につながっている MIDI の入力ポートと出力ポートを選んでください（方向を入れ替えるのを忘れずに。コンピュータの MIDI 出力を AMYboard の MIDI 入力へ、逆も同様です）。

MIDI 経由で AMYboard から最新のスケッチとノブ設定を取得する間、短い「syncing」のウィンドウが表示されます。AMYboard がまだ接続されていなければ、ここで接続してください（そのうえで MIDI ポートを選び直します）。

MIDI が正しく配線されているはずなのに sync のウィンドウが長時間出たままの場合は、[ファームウェアの再書き込み](firmware.md)が必要かもしれません。

<img src="../../docs/amyboard/img/pulling.png" width=600>

ウィンドウが消えると、（後述の）ノブと上部のストリップを備えた AMYboard Online のメイン画面が表示されます。

<img src="../../docs/amyboard/img/control.png" width=600>

すぐに AMYboard を使い始められます。画面上のピアノ鍵盤の音をクリックすると AMYboard が反応するはずです。ノブを動かせば AMYboard 側も反応します。

ページの残りの部分を見ていきましょう。

<img src="../../docs/amyboard/img/control_top.png">

**MIDI Input Pass-Thru** では、画面上のノブや鍵盤に加えて、_コンピュータ上の別の MIDI 入力ポート_から AMYboard を制御できるように選択できます。ウェブページで AMYboard を制御しつつ演奏するのに便利です。オンにするかどうかは任意ですが、たとえば MIDI コントローラをコンピュータにつないでいるなら、それを選べば AMYboard を直接演奏できます。

"Switch to Simulate" を押すと Simulate モードに移ります。次に説明します。

上部のタブ:

 - Patch - シンセサイザーのチャンネルごとのノブと設定
 - Code - スケッチファイルと、シーケンサの操作
 - AMYboard World - スケッチの閲覧、ダウンロード、自作スケッチのアップロード
 - Upgrade Firmware - ウェブから直接[新しいファームウェアを書き込みます](firmware.md)
 - Reset - AMYboard をデフォルトにリセットして再起動します

"Write Sketch & Knobs to AMYboard" は、AMYboard 上で動いている内容を現在の状態で置き換えます。次に電源を入れ直したときも同じ音にしたい場合は、これを実行してください。


## Simulate モード

Simulate モードを選ぶと、ブラウザ内で AMYboard が動きます。実機の AMYboard と同じ音を出し、同じスケッチを動かせます（細かな違いはいくつかありますが、ほとんどの人は気づかないでしょう）。シンセ環境から離れた場所で AMYboard のスケッチを開発するのに最適です。

シミュレート時のページは少し異なります。

<img src="../../docs/amyboard/img/simulate_top.png">

- MIDI in と out - シミュレートされた AMYboard の MIDI ポートです。シミュレータを MIDI で制御したい場合は MIDI 入力ポートをつないでください。シミュレータから MIDI を送出したい場合（[wave=amy.MIDI](https://github.com/shorepine/amy/blob/main/docs/api.md) を使用）は、MIDI 出力ポートも選んでください。
- Allow Audio Input - ウェブでは、ブラウザに音声入力の使用を手動で許可する必要があります。これは AMY のエフェクト（`amy.AUDIO_IN0` など）とサンプリングにのみ使います。
- Switch to Control - Control モードに戻ります。

### パッチエディタ

パッチエディタはどちらのモードでも同じように動きます。Simulate モードではブラウザ内で動く AMYboard を操作していることを忘れないでください。Control モードでは、ノブを動かすたびに実機の AMYboard がリアルタイムに変わります。


<img src="../../docs/amyboard/img/channel_strip.png">

上部のチャンネルストリップでは、16 の MIDI チャンネルごとに異なるパッチを使えます。

| コントロール | 説明 |
|---------|-------------|
| **Channel 1**（ドロップダウン） | 編集する 16 の独立したシンセチャンネルのどれかを選びます。各チャンネルは自分のパッチ、MIDI 割り当て、パラメータ一式を持ちます。 |
| **Active**（チェックボックス） | このチャンネルを有効／無効にします。チェックを外すと、設定を失わずにチャンネルを無音にします。 |
| **Load Preset**（ボタン） | クリックするとプリセットブラウザが開き、内蔵の 256 プリセットのいずれかを現在のチャンネルに読み込めます。 |
| **Clear** | このチャンネルのすべてのノブをデフォルト値に戻します。 |
| **Level** | このチャンネルの相対的な音量を設定します |


"Load Preset" をクリックすると、プリセットのドロップダウンが表示されます。

<img src="../../docs/amyboard/img/presets.png" width=600>


チャンネルストリップの下には、音のパラメータを設定するノブがあります。



<img src="../../docs/amyboard/img/patch_knobs.png" width=700>

パッチのノブパネルは 6 つのセクションが 2 列に配置されています。左列（ピンク）はオシレータと LFO を、右列（青）はフィルタとエンベロープを制御します。

#### OSC A — オシレータ A

| ノブ | 説明 |
|------|-------------|
| **freq** | オシレータ A の基準周波数（Hz）。デフォルトは 440（コンサートピッチの A）。 |
| **wave** | 波形の選択。クリックで SINE、PULSE、SAW\_UP、SAW\_DOWN、TRIANGLE、NOISE などを切り替えます。 |
| **duty** | PULSE 波形のパルス幅（0〜1）。他の波形には影響しません。 |
| **level** | オシレータ A の出力レベル（振幅、0〜1）。 |

<img src="../../docs/amyboard/img/wavetable_presets.png" width=250>

*ウェーブテーブルの波形を選ぶと、Wavetable Presets のドロップダウンから内蔵のウェーブテーブルファイルを選べます。*

#### OSC B — オシレータ B

| ノブ | 説明 |
|------|-------------|
| **freq** | オシレータ B の基準周波数（Hz）。デフォルトは 220（OSC A の 1 オクターブ下）。OSC A からわずかにデチューンすると音が太くなります。 |
| **wave** | オシレータ B の波形選択。OSC A とは独立です。 |
| **duty** | オシレータ B の PULSE 波形のパルス幅。 |
| **level** | オシレータ B の出力レベル（0〜1）。 |

#### LFO — 低周波オシレータ

| ノブ | 説明 |
|------|-------------|
| **freq** | LFO のレート（Hz）。ビブラートやトレモロには通常 10 Hz 以下の値を使います。 |
| **wave** | LFO の波形（TRIANGLE、SINE、SAW、PULSE など）。 |
| **osc** | LFO がオシレータのピッチをどれだけ変調するか（0〜1）。ビブラートになります。 |
| **pwm** | LFO が OSC A / B のパルス幅をどれだけ変調するか（0〜1）。パルス幅変調になります。 |
| **filt** | LFO が VCF のカットオフ周波数をどれだけ変調するか（0〜1）。フィルタのうねりになります。 |

#### VCF — 電圧制御フィルタ

| ノブ | 説明 |
|------|-------------|
| **freq** | フィルタのカットオフ周波数（Hz）。値が小さいほど暗く低音寄りに、大きいほどフィルタが開きます。 |
| **resonance** | フィルタのレゾナンス（Q、0〜1）。値が大きいほどカットオフ付近のピークが鋭くなります。極端な値ではクリップすることがあります。 |
| **kbd** | キーボードトラッキングの量（0〜1）。1.0 ではフィルタのカットオフが MIDI ノートに追随し、高い音ほど明るくなります。 |
| **env** | 後述の VCF ENV がフィルタのカットオフをどれだけ変調するか。値が大きいほどノートごとのフィルタスイープが大きくなります。負の値にすると、アタック時に下方向へスイープします。 |

#### VCF ENV — フィルタエンベロープ

| ノブ | 説明 |
|------|-------------|
| **attack** | ノートオン後、フィルタエンベロープがピークに達するまでの時間（ms）。 |
| **decay** | フィルタエンベロープがピークからサステインレベルまで下がる時間（ms）。 |
| **sustain** | キーを押している間に保持されるフィルタエンベロープのレベル（0〜1）。 |
| **release** | ノートオフ後、フィルタエンベロープがサステインからゼロまで下がる時間（ms）。 |

#### ADSR — 振幅エンベロープ

| ノブ | 説明 |
|------|-------------|
| **attack** | ノートオン後、最大音量に達するまでの時間（ms）。 |
| **decay** | 音量がピークからサステインレベルまで下がる時間（ms）。 |
| **sustain** | キーを押している間に保持される音量レベル（0〜1）。 |
| **release** | ノートオフ後、音が消えるまでの時間（ms）。 |


<img src="../../docs/amyboard/img/effects_knobs.png" width=220>

エフェクトパネル（Patch タブの右側）には、全チャンネルで共有される 4 つのグローバルプロセッサがあります。

#### EQ — 3 バンドイコライザ

| ノブ | 説明 |
|------|-------------|
| **low** | 低域（\< 800 Hz）のシェルビングゲイン（dB）。正の値で低音をブースト、負の値でカットします。 |
| **mid** | 中域のゲイン（800 Hz〜7 kHz）。 |
| **high** | 高域（\> 7 kHz）のシェルビングゲイン。正の値で明るさを加え、負の値で高音を落とします。 |

#### Chorus（コーラス）

| ノブ | 説明 |
|------|-------------|
| **level** | コーラスの wet/dry ミックス（0〜1）。0 = ドライ、1 = フルコーラス。 |
| **freq** | コーラス LFO のレート。値が大きいほど速く強い変調になります。 |
| **depth** | コーラスの深さ。ピッチ変調の振れ幅です。深いほど太く、ゆらぐ音になります。 |

#### Reverb（リバーブ）

| ノブ | 説明 |
|------|-------------|
| **level** | リバーブの wet/dry ミックス（0〜1）。 |
| **live** | 部屋の広さ／減衰時間（0〜1）。値が大きいほど長く広がるリバーブテールになります。 |
| **damp** | リバーブテールの高域減衰（0〜1）。値が大きいほど温かく、耳障りでない響きになります。 |

#### Echo（エコー）

| ノブ | 説明 |
|------|-------------|
| **level** | エコーの wet/dry ミックス（0〜1）。 |
| **delay** | エコーのディレイタイム（ミリ秒）。 |
| **feedback** | エコー信号をどれだけ自分自身に戻すか（0〜1）。値が大きいほど長く繰り返すエコーになります。暴走を避けるため 1 未満に保ってください。 |


### MIDI CC とノブのパラメータを設定する

<img src="../../docs/amyboard/img/knob_modal.png" width=250>

ノブの**ラベル**（ノブの上下にある "freq" などの文字）をクリックすると、そのパラメータエディタのポップアップが開きます。

| 項目 | 説明 |
|-------|-------------|
| **min / max** | このノブがカバーする実際の値の範囲。たとえば OSC A の freq はデフォルトで min 50 Hz / max 2000 Hz です。範囲を狭めると、より小さな幅で細かく操作できます。 |
| **log** | チェックすると、ノブが対数スケールに従います。大きな値ほど知覚上の重要度が下がる、周波数や時間のパラメータで便利です。 |
| **MIDI CC (0-127)** | このノブに MIDI のコンティニュアスコントローラ番号を割り当てます。コントローラがその CC を送ると、ノブがリアルタイムに動きます。空欄なら CC の割り当ては行われません。 |
| **Learn** | Learn をクリックしてから、MIDI コントローラのノブやフェーダーを動かします。CC 番号が自動検出されて入力されます。 |
| **Save / Cancel** | Save で新しい範囲と CC の割り当てを確定します。Cancel は何も変更せずに閉じます。 |



## Python のスケッチを書いて実行する

AMYboard は、ウェブでも実機でも、起動時に（スケッチに保存されたデータを使って）各チャンネルに設定されたパッチを構成し、その後 `sketch.py` に設定された「スケッチ」を実行します。これは Python のプログラムで、セットアップのコード（ファイルのトップレベル）を実行したうえで、定期的に `loop(tick)` を呼びます。呼ばれるのはシーケンサの 32 分音符ごとで、小節の頭から始まります。間隔にすると `7500 / tempo` ms（デフォルトのテンポ 108 では 69 ms）です。`tick` は AMY シーケンサの絶対ティック数で、`sequencer.AMYSequence` のイベントや `amy.send(ticks=...)` が使うのと同じクロックなので、そのまま渡し返せます。32 分音符の数え上げには除算します。`step = tick // amyboard.TICKS_PER_STEP` で小節に同期したステップ番号が得られ、`step % 32 == 0` が小節頭です。この引数は必須です。引数なしの `loop()` は毎回 `TypeError` を送出し、スケッチのループは 8 回連続で失敗すると自ら停止します。より速いコールバックが必要な場合は [`loop()` はどのくらいの頻度で呼ばれますか？](faq.md#how-often-is-loop-called)を参照してください。

<img src="../../docs/amyboard/img/code.png">

AMYboard online の Code タブにはコードエディタがあります。編集できるデフォルトの `sketch.py` が表示されるはずです。

このコードを実行するには、まず "Write Sketch & Knobs to (Simulator / AMYboard)" をクリックしてスケッチを書き込む必要があります。

コードエディタの下には "Start"、"Stop"、"Restart" と、シーケンサのテンポ入力があります。これらでスケッチの loop() コールバックを開始・一時停止できます。

Simulate モードでのみ、"Terminal REPL" の開閉三角が表示されます。これはブラウザ内の Python REPL で、自分の Python コマンドを入力できます。Control モードでこの REPL が欲しい場合は、シリアル接続で [AMYboard に直接接続](python.md)してください。

<img src="../../docs/amyboard/img/terminal_repl.png" width=600>

*Terminal REPL では、対話的な MicroPython プロンプトで AMY のコマンドを入力し、結果をすぐに確認できます。*

同じく Simulate モードのみ、コードエディタの下に、シミュレートされた [AMYboard のアクセサリ](accessories.md)の列が表示されます。OLED ディスプレイ、押しボタン付きロータリーエンコーダ、2 つの CV 入力ノブが含まれます。アクセサリ付きの実機に展開する前に、ハードウェアの接続を検証するのに役立ちます。

<img src="../../docs/amyboard/img/oled_rotary_cv.png" width=600>


## AMYboard World

AMYboard 向けに「AMYboard World」というファイル共有ネットワークを提供しています。誰でも自分のスケッチを共有できます。共有するかどうかは自由ですが、ぜひ共有をおすすめします。アップロードを知らせるために、[Discord](https://discord.gg/TzBFkUb8pG) にもぜひ参加してください。


<img src="../../docs/amyboard/img/abw_sketches.png" width=600>

みんながアップロードしたスケッチを検索したり眺めたりできます。スケッチにはパッチとコードの両方が含まれます。オンラインでも実機でも、AMYboard は同時に 1 つのスケッチだけを動かします。環境をクリックすると、現在の構成が AMYboard World のものに置き換わります。

<img src="../../docs/amyboard/img/amyboard_world_upload.png" width=600>

ここから自分の環境やパッチをアップロードできます。覚えやすいユーザー名を選び、作品の説明を書いてください。

AMYboard World のスケッチは、任意の Python REPL からも取得して実行できます。AMYboard 上でも、Tulip CC / Tulip Desktop 上でも、両方のウェブ版でも使えます。

```python
world.amyboard.ls()                          # 最近のスケッチを一覧表示
world.amyboard.download("eno_ambient", "dpwe")  # スケッチをダウンロードして開始
```

Tulip 上では、スケッチは AMYboard と同じように開始されます（シンセをリセットし、保存済みのノブ状態を適用し、`loop()` をシーケンサに載せる）。CV の入出力呼び出しは何もしませんが、OLED ディスプレイやロータリーエンコーダといった I2C アクセサリは動作します。
