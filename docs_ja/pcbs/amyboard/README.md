## リビジョン

- **v1.5**（`amyboard-v1.5.sch` / `.brd`、Makerfabs 版）— CV とオーディオの回路は v1.4 と同じで、負電源レールのレギュレータが SGM2209-ADJ に変更されました（-12V のまま）。なお v1.5 の量産分に載っている GP8413 DAC は、出力レンジが半分の状態で起動する新しいデートコードのロットです。[CV のトラブルシューティング項目](../../amyboard/troubleshooting.md#cv-out-voltages-are-wrong-v15-boards)を参照してください。
- **v1.4** — 最初の量産リビジョン（`amyboard-v1.4.sch` / `.brd`。上の PNG）。
- **v1.0 / v1.1dpwe** — 試作品。
