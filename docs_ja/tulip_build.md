# 自分だけの Tulip Creative Computer を作る

![Custom Tulip laptop](https://raw.githubusercontent.com/shorepine/tulipcc/main/docs/pics/hinge.jpg)

[Tulip CC の完成品を買うのではなく](https://tulip.computer)自分で [Tulip Creative Computer](../README.md) を作って使い始めるには、4 つの方法があります。

 * [ハードウェアはいらない。とりあえずデスクトップ PC で Tulip Desktop か Tulip Web を動かしたい。](tulip_desktop.md) Tulip に興味があってまず試してみたい人向けです。気に入ったら実機にアップグレードできます。
 * [ジャンパワイヤとブレッドボードで、とりあえずの Tulip を組みたい。](tulip_breadboard.md) はんだ付けが得意でない人や、とにかく素早く Tulip を組み上げたい人向けです。配線が多いので安定性は低く、持ち運びや移動には向きませんが、ちゃんと動きます。
 * [スルーホールのはんだ付けはできるので、ブレークアウト基板でもう少し信頼性の高い Tulip を作りたい。](tulip_breakout.md) スルーホールのはんだ付けに慣れていて、既製のブレークアウトボードをつなぎ合わせて信頼性の高い Tulip を作りたい人向けです。必要なものをすべて橋渡しする安価な PCB を購入できます。統合された Tulip ボードより嵩張りますが、動作は同じです。
 * [1 枚基板の Tulip を作りたい。SMT のはんだ付けができるか、実装サービスを使える。](tulip_board.md) これは最上位の選択肢です。ディスプレイ、オーディオ、MIDI、キーボード用のコネクタを備えた、完全統合の Tulip ボードです。Raspberry Pi のようなもので、それが Tulip というわけです。ただし、優れたはんだ付けスキル（小さな SMT 部品と FPC コネクタが多数あります）か、JLCPCB、PCBway、Aisler のような実装サービスの利用が必要です。

 Tulip Creative Computer が組み上がったら、次は[ファームウェアのコンパイルと書き込みの方法を学びましょう。](tulip_flashing.md)
